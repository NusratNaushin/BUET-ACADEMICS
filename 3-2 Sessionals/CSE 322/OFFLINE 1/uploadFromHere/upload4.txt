🔹 2. Atomic variables (AtomicInteger, AtomicBoolean, etc.)

AtomicInteger counter = new AtomicInteger();

Thread-safe without synchronized blocks.

    fileSize (long) — in bytes (decide and be consistent)

2. Server:

    checks if (Server.usedBufferSize + fileSize > Server.MAX_BUFFER_SIZE) → reject if true

    else:

        decrease/mark buffer reserved: Server.usedBufferSize += fileSize; (or reserve per-file chunk sum as you receive)

        picks chunkSize and fileId

        sends confirmation reply: {accepted:true, chunkSize: int, fileId: String}

3. Client:

    splits file into chunks of chunkSize

    sends each chunk sequentially:

        send chunk metadata (fileId, chunkIndex, chunkLength) then the raw bytes (byte[])

        waits for server ACK after each chunk

4. Server:

    receives chunk bytes, writes them into a temp file (or stores chunks),

    sends ACK for each chunk,

    on last chunk, server verifies sum of chunks equals declared fileSize:

        if match → rename temp to final file path, mark metadata, log success

        else → delete temp, reduce Server.usedBufferSize, log failure

5. Notification & history:

    If upload was for a requestId → server looks up the request owner(s) and sends them a message that file is uploaded.
